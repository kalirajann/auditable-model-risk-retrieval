# Mortgage Default and Prepayment Model — Independent Validation

INDEPENDENT VALIDATION — SUPERSEDED
Validation of version 5.0 reported default calibration error of 0.041. Testing covered conceptual soundness, implementation verification, sensitivity analysis, and outcomes analysis. The principal limitation was that rapid interest-rate reversals are weakly represented in the historical sample. This validation was superseded by MDP-VAL-v2 on 2025-11-15.
