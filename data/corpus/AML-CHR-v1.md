# AML Transaction Monitoring Prioritization Model — Model Charter

MODEL CHARTER — SUPERSEDED
The AML Transaction Monitoring Prioritization Model is used to prioritize transaction-monitoring alerts for investigator review. Model version 1.8 is owned by Noah Williams in Financial Crimes Compliance. It is classified Tier 1. The operating decision threshold is 0.73. This charter was effective from 2025-01-15 through 2025-09-30 and was replaced by CHR-v2. Do not use this version for decisions on or after 2025-10-01.
