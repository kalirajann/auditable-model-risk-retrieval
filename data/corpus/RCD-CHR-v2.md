# Retail Credit Default Model — Model Charter

MODEL CHARTER — CURRENT
The Retail Credit Default Model is used to estimate 12-month probability of default for unsecured retail loans. Approved model version 3.0 is owned by Marcus Lee in Consumer Lending Risk. It is classified Tier 1. The current operating decision threshold is 0.58. This charter supersedes RCD-CHR-v1 effective 2025-10-01. Required control: quarterly performance monitoring and annual independent validation.
