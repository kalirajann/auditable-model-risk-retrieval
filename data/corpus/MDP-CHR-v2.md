# Mortgage Default and Prepayment Model — Model Charter

MODEL CHARTER — CURRENT
The Mortgage Default and Prepayment Model is used to forecast mortgage default and voluntary prepayment over a 12-month horizon. Approved model version 5.2 is owned by Samuel Reed in Mortgage Portfolio Risk. It is classified Tier 2. The current operating decision threshold is 0.54. This charter supersedes MDP-CHR-v1 effective 2025-10-01. Required control: quarterly calibration monitoring and annual independent validation.
