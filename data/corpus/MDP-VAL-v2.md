# Mortgage Default and Prepayment Model — Independent Validation

INDEPENDENT VALIDATION — CURRENT
Validation of approved version 5.2 reported default calibration error of 0.034. Independent testing covered conceptual soundness, implementation verification, sensitivity analysis, outcomes analysis, and review of use. The remaining limitation is that rapid interest-rate reversals are weakly represented in the historical sample. Validation approved use subject to quarterly calibration monitoring and annual independent validation. This report supersedes MDP-VAL-v1.
