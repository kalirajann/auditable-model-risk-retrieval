# AML Transaction Monitoring Prioritization Model — Development Report

DEVELOPMENT REPORT
Purpose: prioritize transaction-monitoring alerts for investigator review. Development data consist of synthetic transaction-network features and de-identified alert outcomes from 2022-2025. Records were de-identified or synthetic before modeling. Time-based sampling was used: earlier observations for development and later observations for holdout testing. The report documents transformations, missing-value rules, feature definitions, and reproducible code parameters. Known limitation: cross-border correspondent activity has sparse confirmed-positive labels. No customer names, account numbers, or raw protected-attribute values are retained in this benchmark record.
